# @meta-agentic/meta-graph

The aggregator: depends on `@meta-agentic/graph-model`, `graph-react` and `graph-query` at the same version and re-exports them as namespaces, so a consumer that wants the whole toolkit installs one name. Nothing lives here but that.

```js
import { model, react, query } from '@meta-agentic/meta-graph'
```
