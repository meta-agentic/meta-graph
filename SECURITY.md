# Security policy

## Reporting a vulnerability

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this repository. Please do not open a public issue for it.

You will get an acknowledgement within a week. A confirmed vulnerability is fixed in a new release of every affected package, and the advisory is published once the release is available.

## Supported versions

The latest release of each package receives fixes. The packages are released together, at one version.

## Scope

The packages parse graph files that may come from anywhere. Reports are especially welcome on: a reader that can be made to consume unbounded memory or time, a query that escapes its step budget, and markup in a graph's labels that reaches a page as HTML instead of text.
